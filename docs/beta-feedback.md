# Beta feedback

Everything found in phase 14: Reuben's manual pass (`docs/manual-test-script.md`) and the user testing with
about 5 parents and 5 sitters on staging. Reuben passes feedback on in chat; Claude Code logs it here, fixes
what's marked **must-fix** (each with tests), and updates the status.

## How items are written

- **ID:** `M` for the manual pass, `U` for user testing, then a number (M1, M2, U1 …). IDs are never reused.
- **Who:** a role and a tester code, never a name: `P1`–`P5` for the parents, `S1`–`S5` for the sitters, `R`
  for Reuben. Keep testers' names, numbers and emails out of this file (it's in the repo).
- **Where:** the page, or the step number from the manual test script (for example "6.3").
- **What happened:** what they did, what they expected and what happened instead, in their words where
  possible.
- **Severity:**
  - **must-fix:** wrong money, a safety or privacy problem, someone stuck (can't sign up, book, pay, check
    in or be paid), or copy claiming something we don't do. Fixed before launch.
  - **should-fix:** confusing or clumsy, but there's a way through. Fixed before launch if there's time.
  - **later:** an idea or a nice-to-have. Goes to the v2 backlog in `progress.md`.
- **Status:** `open`, `fixing`, `fixed (PR #…)`, `won't fix (why)`, or `needs Reuben` (a business decision;
  also added to "Open questions" in `progress.md`).
